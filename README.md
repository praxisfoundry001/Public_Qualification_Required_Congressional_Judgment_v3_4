# Public Qualification and Required Congressional Judgment

**Proposed Amendment to the Constitution of the United States**

## Overview

This proposed constitutional amendment establishes six independent public and governmental qualification channels through which formally introduced congressional measures may become entitled to a recorded final vote.

The proposal establishes verification requirements, legislative-text identity protections, voting deadlines, and administrative accountability mechanisms.

Qualification does not compel Congress to approve legislation, prescribe how any member votes, or alter existing constitutional requirements for passage or constitutional amendment.
